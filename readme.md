1 Introduction Traditional wireless image communication systems employ a two-step encoding process. The first step removes redundant information through source coding, and the second step protects transmitted information with error correction codes to combat errors introduced by wireless channels. According to Shannon's separation theorem [1], in the asymptotic limit where block length approaches infinity, this separation architecture is theoretically optimal. In practice, efficient compression algorithms and channel coding that achieve the channel capacity are used to achieve near-optimal performance when block lengths are reasonable. However, from the Internet of Things to autonomous driving and even tactile internet applications, there is a need for transmitting image data under extremely high latency, bandwidth, or energy constraints. This makes advanced source coding and channel coding techniques with high computational complexity and long block lengths difficult to apply.
In recent years, deep learning (DL) methods, particularly autoencoders [2,3], have achieved remarkable results in the field of image compression, with performance even surpassing state-of-the-art lossy compression algorithms [4-6]. Compared to traditional compression algorithms, DL-based lossy compression methods have unique advantages: by leveraging deep architectures, they can extract complex features from training data; simultaneously, through backpropagation, their model parameters can be efficiently trained on large datasets. Meanwhile, the similarity between autoencoder architectures and digital communication systems inspires researchers to use autoencoder architectures for end-to-end communication system modeling [7,8]. Examples of such designs include: decoder design for existing channel codes [9,10], blind channel equalization [11], learning physical layer signal representations for single input single output (SISO) [8] and multiple input multiple output (MIMO) [12] systems, and joint source-channel coding for text messages [15].
2 Problem Modeling Our research focuses on image transmission in point-to-point noisy wireless communication channels. The transmitter maps the input image into a complex number valued channel input symbol vector that satisfies the power constraint of the transmission. According to related literature on joint source-channel coding, we refer to the dimensionality of the image as the source bandwidth, and the dimensionality of the channel as the channel bandwidth. Typically, this situation is known as bandwidth compression. Due to noise, fading, interference, or other channel impairments, the channel causes signal quality degradation. The degraded output of the communication channel is transmitted to the receiving end, which then generates an approximate reconstruction image of the original input image.
Figure 1 (a) illustrates the encoding and decoding process of a typical digital transmission system [16]. Although each module in this processing flow may be highly optimized, the system performance can significantly decrease when the channel conditions deviate from the conditions set by the system optimization. When the channel capacity is lower than the designed channel code rate, due to the strong inverse theorem of channel coding, the bit error rate approaches 1, making it impossible for the receiver to receive the correct channel code word. This also leads to the failure of the source decoder, resulting in a significant degradation in image reconstruction quality. Moreover, this separation design cannot take advantage of the advantages brought by improving channel conditions: once the source code rate and channel code rate are determined according to the target channel quality, regardless of how much the channel condition improves compared to the target condition, the image reconstruction quality will not change. These two characteristics are known as "cliff effects". Several joint source-channel coding schemes have been proposed in the literature to overcome this defect [17,18].
In this paper, we adopt a completely different approach, drawing inspiration from uncoded transmission [19-21] by directly mapping real pixel values into complex numerical samples transmitted through the communication channel, as shown in Figure 1 (b). Our goal is to design a joint source-channel coding scheme that avoids the process of first converting pixel values into a bit sequence and then mapping that bit sequence back into a real-valued input for the channel; instead, this scheme directly maps pixel values to the channel input. This is similar to recent analog transmission techniques [20,21], primarily because it does not restrict the mapping to linear transformations.

Conclusion: We propose a novel deep joint source-channel coding architecture for image transmission over wireless channels. In this architecture, the encoder maps the input image directly into the channel input. The encoding function and decoding function are modeled as complementary deep neural networks, and they are jointly trained on a dataset to minimize the mean square error in reconstructing the image. Numerical simulation results show that the performance of the deep joint source-channel coding scheme is superior to the scheme based on separate architectures, especially in scenarios with limited channel bandwidth and low SNR. More importantly, experiments confirm that the performance of the deep joint source-channel coding scheme exhibits a smooth decline in image quality with changes in channel SNR. Leveraging this characteristic, the scheme demonstrates significant advantages in slow fading channel communication. Despite not requiring pilot signals or explicit channel estimation, the deep joint source-channel coding scheme achieves good performance across all average SNR conditions and outperforms the proposed separate architecture transmission scheme in any channel bandwidth condition.
